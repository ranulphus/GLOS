# PDF Viewer

Reads PDF files, a page at a time.

| Keys | What they do |
|---|---|
| Ctrl+O | Open a file |
| Ctrl+PgDn, Ctrl+PgUp | The next page, the page before |
| Ctrl+Home, Ctrl+End | The first page, the last |
| Ctrl+G | Go to a page by its number |
| Ctrl++, Ctrl+- | Larger, smaller |
| Ctrl+1 | The page's real size |
| Ctrl+2 | As wide as the window |
| Ctrl+F, F3, Shift+F3 | Find words in the whole file; the next place, the one before |
| Ctrl+T | Select Text: the mouse chooses text (press it again: the mouse moves the page again) |
| Ctrl+C | Copy the text chosen, or the whole page's when none is |
| F9 | The file's outline (its chapters), at the left |

The arrows, the wheel and the scroll bars move over the page; so does dragging it with the left button.

- A file that needs a password asks for it. Files locked only against printing or copying open as they are.
- A file that does not carry its own fonts is shown in GLOS's.
- There is no printing, and pages are not saved as pictures.
