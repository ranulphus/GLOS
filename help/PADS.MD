# Keyboards, mice and game pads

## Keyboards and mice

PS/2 and USB keyboards and mice work, a USB hub between them and the PC included. The Control Panel's
**Input** page sets how fast keys repeat, the pointer's speed and the double-click time; its **Region** page
sets the keyboard's layout (US or UK).

In a DOS program the mouse is a PS/2 mouse, whichever kind it really is. The program still needs a DOS mouse
driver loaded, as it would in DOS alone.

## Game pads

USB game pads and Xbox pads are found when plugged in; the task bar shows a small pad, and a notification
says which. To a DOS game a pad is an ordinary joystick on the game port:

- the left stick and the direction pad are joystick A, the right stick is joystick B;
- buttons A, B, X and Y are the joysticks' four buttons;
- a second pad becomes joystick B.

Choose "joystick" or "game pad" in the game's set-up and calibrate there if it asks. The Control Panel's
**Joystick** page shows the pads as you move them and changes which stick and button is which.

## If the PC's own USB support is wanted

The Control Panel's **USB** page can leave the USB ports to the PC's BIOS, as DOS alone has them. USB pads
then do not reach DOS games.
