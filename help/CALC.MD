# Calculator

Three calculators in one, chosen in the **View** menu.

## Standard

Works each sum as it comes: 2 + 3 * 4 is 20. Type on the keyboard or press the buttons.

| Keys | What they do |
|---|---|
| 0 to 9, . or , | Digits and the decimal mark |
| + - * / | The four sums |
| Enter or = | The answer |
| Esc | Clear everything (C) |
| Del | Clear what is being typed (CE) |
| Backspace | Take a digit back |
| % | Per cent |
| @ | Square root |
| r | One divided by the number |
| F9 | Change the sign |
| Ctrl+M, Ctrl+R, Ctrl+P, Ctrl+L | Memory: store, recall, add to it, clear it |

## Scientific

Builds the whole sum and works it in the usual order, with brackets: 2 + 3 * 4 is 14.

| Keys | What they do |
|---|---|
| ( ) | Brackets |
| ^ | To the power of |
| s, c, t | sin, cos, tan |
| l, n | log (base ten), ln |
| p | pi |
| ! | Factorial |
| m | Remainder (mod) |
| i | Inv: the next function's inverse |

The Deg button goes round degrees, radians and grads.

## Programmer

Whole numbers in 8, 16, 32 or 64 bits, signed or not, shown at once in sixteens, tens, eights and twos. The
bits can be pressed one by one.

| Keys | What they do |
|---|---|
| a to f | The digits above nine |
| & ^ ~ and the upright bar | AND, XOR, NOT, and OR |
| < > | Shift left and right |
| % | Remainder |
| F5, F6, F7, F8 | Base 16, 10, 8, 2 |
| F12, F2, F3, F4 | 64, 32, 16, 8 bits |

## History

**View, History** lists the sums done (standard and scientific); press one to take its answer again.
**Ctrl+C** copies the number shown, **Ctrl+V** pastes one.
