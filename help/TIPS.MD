# Tips

Help shows one of these each time the desktop comes on, if you ask it to: **Tip of the day** on the Control
Panel's Desktop page, or the box in the tip's own window.

- Press F1 in any program to open its page of this guide.
- Open the Start menu and type a few letters: programs and settings are found by their names.
- Ctrl+F in the Control Panel finds a setting by a word.
- Hold Alt and press Tab to go from window to window.
- Drag a window to the screen's edge and it snaps there. The Control Panel's Desktop page turns that off.
- The task bar can sit at the top of the screen: the Control Panel's Desktop page.
- Type DEVICES at GLOS's prompt for every device of the PC and what serves it; the Control Panel's Devices
  page shows the same.
- A DOS game that will not run under GLOS may run in direct mode: give it a profile on the Control Panel's
  Programs page.
- Save a connection in the Terminal's Sessions, then type ssh and its name at any prompt to open it.
- Files opens another PC's folders over SFTP, by a saved session.
- Fall Line keeps your best run as a ghost to race against.
- In Cushion, press O on one PC and J on the others to play over the network: no addresses to type.
