# Monitor

Monitor shows what the PC is doing, on six pages. **Ctrl+Alt+Del** on the desktop opens its first page.

- **Programs:** everything running, with how much of the processor and memory each is using and whether it is
  answering. **Switch To** brings one to the front; **End Program** ends it (what it had not saved is lost).
- **Performance:** the processor's use over the last minute, memory in use, and the network's traffic.
- **System:** GLOS's version and how long it has run, the processor, memory, the screen and its card, the
  sound card, the network card and address.
- **Log:** the last lines of GLOS's own log. Useful when [something goes wrong](TROUBLE.MD).
- **Services:** the programs GLOS starts with itself and keeps running; stop one or start it again.
- **Windows:** every window and whose it is; **Go To** brings one to the front.

A program that has stopped answering has "(not answering)" in its title. If it stays so, end it here.
