# Games

Keeps your DOS games in one place. Games looks in the folders you give it (to begin with, C:\GAMES), knows
many well-known games by their files, and shows each with its title, year and maker.

| Keys | What they do |
|---|---|
| Enter | Play the chosen game |
| F5 | Look through the folders again |
| Ctrl+N | Add a game by its program |
| Ctrl+D | A favourite, or not |
| Ctrl+B | Favourites only |
| Ctrl+F | Find: type a piece of a title, a maker or a kind |
| Ctrl+1, Ctrl+2 | As pictures, as a list |
| Alt+Enter | The game's properties |
| Del | Take the game off the list (nothing on the disk is touched) |

- **File, Add Folder** adds a folder of games to look through. The folders are watched: a game copied into one while the
  Games Library is open appears a few seconds later.
- **Game, Set Up** runs the game's own set-up program, where it has one: choose Sound Blaster 16 there.
- **Properties** gives a game a title of your own, a picture, and notes. Its lower part says how the game's
  program runs: in a window or on **the whole screen**, how much **memory** it is given (empty: all there
  is), the **Sound Blaster** it is told of (as DOS's BLASTER has it, A220 I5 D1 H5 T6; empty: as GLOS tells
  every program), its **pad mapping** (which of the pad's sticks and buttons work its game port, as the
  Control Panel's Joystick page's Mapping says it for every program: `lx ly rx ry 1 2 3 4`; empty: that
  one), and **direct mode**, which gives the game the PC's ports for itself, for a game that won't run
  otherwise. These are the program's own settings, for every copy of it (the Control Panel's Programs
  page shows them too).
- The **View** menu sorts by title, by when a game was last played, or by the time played. Games counts how
  often and how long you play each.

A game has the whole screen while it runs; Games comes back when it ends. See
[DOS programs and games](DOSPROGS.MD).
