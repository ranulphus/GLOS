# The desktop

The desktop is GLOS's own screen: icons on a background, the task bar along one edge, and the windows of the
programs you have started.

## Icons

- There is an icon for each drive from C: up, for Files, Terminal, Notepad, Calculator, Images, Monitor, the
  Control Panel and Paint, for any program you have put on the desktop, and for the Recycle folder.
- Double-click an icon to open it. With the keyboard: the arrows, Home and End move, a letter jumps to a name,
  Enter opens.
- Drag an icon to put it where you like. Its place is kept.
- The picture behind them, or a plain colour, is chosen on the Control Panel's Desktop page: GLOS's own four pictures are in the WALLS folder beside GLOS.

## The Start menu

Open it with the GLOS mark at the end of the task bar, with **Ctrl+Esc**, or with the Windows key.

- **Type to search.** Programs come first, then the Control Panel's pages, your recent documents and files on
  the hard drives (from two letters on). The last row, "Run:", opens a folder or a file by its path, or runs
  what you typed as a command.
- **With nothing typed** you see what was added lately, what you use most, and every program by its letter.
- **The tiles at the right** are the programs you have pinned. Drag them into the order you want.
- **The buttons at the bottom:** Settings, Files, More and Power.
  - *More* is for the program chosen: open it, pin it to Start or unpin it, move its tile, its recent
    documents.
  - *Power:* Exit GLOS (back to DOS), Restart GLOS, Restart the PC.
- Keys: Down goes into the list, Tab to the tiles, Enter opens, Esc goes back and then away.

## The task bar

From one end to the other: the GLOS mark, a button for each window, a few small icons, and the clock.

- **A window's button** brings the window to the front, or puts it away if it is in front already. The right
  mouse button on it gives Restore, Minimise, Maximise and Close.
- **The clock:** press it for a month's calendar; press it twice for the Date and Time settings.
- **The loudspeaker** (on a PC whose sound card GLOS plays through): press it for the volume and Mute; the
  mouse wheel over it changes the volume; press it twice for the [Mixer](MIXER.MD).
- **The network:** its tooltip is the PC's address; press it for the card, the address and the gateway.
- **Game pads:** press it to see the pads GLOS has found.
- **Notifications** are small windows that come up by these icons and go again after a few seconds: the
  network came up, a program is not answering, a disk is nearly full. "Quiet" on the Control Panel's Desktop
  page holds them back; the bar then shows how many are waiting.

The bar can be at the top of the screen, and can hide itself: the Desktop page again.

## Windows

With the mouse: the boxes at the right of a title bar put a window away, make it fill the screen, and close
it. Double-click the title to fill the screen. Drag any edge or corner to change the size. Drag the title to
the left or right edge for half the screen, to the top for all of it.

With the keyboard:

| Keys | What they do |
|---|---|
| Alt+Tab, Alt+Shift+Tab | The next window, and the one before: hold Alt, let go to switch |
| Alt+F4 | Close the window |
| Alt+F7 | Move it with the arrows (Shift: a pixel at a time; Enter keeps, Esc gives up) |
| Alt+F8 | Change its size with the arrows |
| Alt+F9 | Put it away (minimise) |
| Alt+F10 | Fill the screen, or back |
| Alt+Space | The window's own menu |
| Ctrl+Esc | The Start menu |
| Ctrl+Alt+Del | The list of programs, to switch to one or end it |
| Ctrl+Alt+Shift+Esc | End the program in front at once |
| F1 | Help for the program in front |

In menus and dialogs: Alt and an underlined letter, Tab from one field to the next, Enter for the button with
the heavy border, Esc to leave without changing anything.

## The screen saver

The Control Panel's Saver page chooses a saver, how long GLOS waits before it starts, and when the screen is
turned off. The first key or movement of the mouse ends it (and does nothing else). There is no password on
it.
