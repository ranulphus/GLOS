# Player

Plays a list of music and sound files one after another: WAV, MP3, MP2, Ogg Vorbis, modules (MOD, S3M, XM)
and MIDI files (MID, RMI).

| Keys | What they do |
|---|---|
| Ctrl+O | Add files to the list |
| Enter | Play the chosen row |
| F5 | Play, or pause |
| F6 | Stop |
| Ctrl+Left, Ctrl+Right | The file before, the next file |
| Del | Take the chosen files off the list |
| Ctrl+S | Save the list as a playlist (M3U) |

- **File** also adds a whole folder, opens a playlist, and clears the list.
- **Playback, Repeat** starts the list again at its end; **Shuffle** plays it in no order.
- The slider moves through the file; Volume is the Player's own, apart from the [Mixer](MIXER.MD)'s.
- MIDI files are played by the sound card's music chip or a MIDI device. See [Sound](SOUND.MD).
- MP3 and Ogg files need a Pentium. On a slower PC the Player says so and stops the file.
