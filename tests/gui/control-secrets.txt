#loopa-run-only
# The Control Panel's Secrets page (apps/control/status.c; phase D, D5): the store's state; a master password
# set, then taken away again, each in GLOS's own dialog (kernel/wm/deskpass.c: no password passes through the
# program): the new one twice; then the one it has, and none. (On GLOS alone: the host has no store to ask.)
run CONTROL.EXE secrets
wait "Control Panel"
key alt+m
wait "Secrets"
type sesame
key enter
type sesame
key enter
gone "Secrets"
pause 1500
key alt+m
wait "Secrets"
type sesame
key enter
key enter
gone "Secrets"
pause 1500
key esc
gone "Control Panel"
expect CONTROL secrets state=1 password=0
expect CONTROL secrets state=1 password=1
expect CONTROL end
