# Disk Tools' scheduled backups (apps/disks; phase F): Back Up a Folder keeping the newest 10, Again every week, a time that is no
# time refused with the dialog kept, then Friday at 07:45: GLOS's schedule has "backup-WEB" with DISKS's command
# (the backup itself fails at once: nobody answers at 127.0.0.1's port 1); Backup, Scheduled Backups lists it;
# Remove takes it off the schedule.
run DISKS.EXE
wait "Disk Tools"
said DISKS disks 2
key ctrl+b
wait "Back Up a Folder"
key ctrl+a
type C:\\WEB
key alt+c
type glos@127.0.0.1:1
key alt+t
key ctrl+a
type glos-backups/WEB
quick alt+k home down down
quick alt+a home down down down
key alt+m
key ctrl+a
type 7:5
key enter
said DISKS backup no time "7:5"
wait "Backups"
key enter
gone "Backups"
key alt+m
key ctrl+a
type 07:45
quick alt+d home down down down down down
shot week "Back Up a Folder"
key enter
said DISKS scheduled backup-WEB weekly fri 07:45
said DISKS scheduled keep 10
wait "Backups"
key enter
gone "Backups"
key alt+b
key s
wait "Scheduled Backups"
said DISKS scheduled list 1
shot list "Scheduled Backups"
key alt+r
said DISKS unscheduled backup-WEB 0
said DISKS scheduled list 0
key esc
gone "Scheduled Backups"
key alt+f4
gone "Disk Tools"
expect DISKS end
