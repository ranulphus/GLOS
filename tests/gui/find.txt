# Find and Replace (toolkit 2, step C6; docs/v1/toolkit-2.md, Dialogs): GUITEST's line of text, the dialog by keys
# alone, the page searching with gui_match. "fox": Find next twice (both), once more (not found: no wrapping, the
# app's choice), Find previous (the first again); Replace with "cat" (that one, then on to the next), Replace all
# (the rest); then a regular expression with groups, (\w+) (cat) put back as \2 \1 (two words swapped, twice).
run GUITEST.EXE find
wait "GUITEST Find"
key alt+r
wait "Find and replace"
shot replace "Find and replace"
type fox
key alt+n
key alt+n
key alt+n
key alt+v
key alt+p
type cat
key alt+r
key alt+a
key alt+w
key ctrl+a
type (\\w+) (cat)
key alt+x
key alt+p
key ctrl+a
type \\2 \\1
key alt+a
key esc
gone "Find and replace"
shot replaced "GUITEST Find"
key alt+f4
gone "GUITEST Find"
expect GUI find
expect GUI found 16-19
expect GUI found 49-52
expect GUI not found
expect GUI replaced: The quick brown cat jumps over the lazy dog. The fox is quick.
expect GUI replaced 1: The quick brown cat jumps over the lazy dog. The cat is quick.
expect GUI replaced 2: The quick cat brown jumps over the lazy dog. cat The is quick.
expect GUI end
