#loopa-run-only (its programs run in Loop A only: the host runs none, so its expects are for the suite)
# The terminal's programs (apps/term; M9 step E, PRD D51), in Loop A only: their output and keys in the window,
# a batch file with a variable the shell set, exit codes with ||, a program that takes the screen and gives it back.
# (After a program that takes the screen the script waits until it has ended, by `settle`: how long a session
# is depends on the card and the load, and what is typed during it is the program's, kept only as far as the
# BIOS's fifteen keys.)
run TERM.EXE -log
wait "Terminal"
# (its shell ready for keys: the screen shown, and still, with the shell's greeting, which the host's player
# never has: this script is Loop A's alone. On the 486 natively the
# first keys typed as the window came went nowhere: "c:" and "cd \g" lost, "ui" left; gate 52, 2026-11-24)
said VT| GLOS shell 1.0. HELP lists its commands.
type c:\n
type cd \\gui\n
type c:\\test\\echoargs one two\n
pause 3000
type set GLOSVAR=from-the-shell\n
type run.bat first\n
pause 3000
type c:\\test\\conin line\n
pause 2000
type typed into it\n
pause 2000
type c:\\test\\conin code 3 || echo failed with %errorlevel%\n
pause 3000
type c:\\test\\conin mode\n
pause 3000
settle
type c:\\test\\conin midmode\n
pause 3000
settle
type echo back\n
pause 1000
type exit\n
gone "Terminal"
expect TERM| C:\GUI>c:\test\echoargs one two
expect TERM| one two
expect TERM| batch first from-the-shell
expect TERM| typed into it
expect TERM| LINE typed into it
expect TERM| failed with 3
expect TERM| MODE done
expect TERM| MID done
expect TERM| back
expect TERM end
