# MIDI Studio's step entry (apps/studio; phase F): Edit, Step Entry (F8), then the PC's keys as a piano: C at the
# cursor, a step of an eighth (240 ticks) as it starts; D after it; Space, a rest; Ctrl+1, the step a sixteenth;
# E; Backspace takes the E away and the cursor back; Shift+V an F with an accent (velocity 127) in its place;
# a chord (C, E and G held together: Z, C and B) at one step; D after it, alone; F8 off. Each note is one step of
# the history: Ctrl+Z takes the D away again. Then all of them a semitone up (Ctrl+Up) and an octave down
# (Ctrl+Shift+Down); Quantise (Ctrl+Q) finds them on sixteenths already; Velocity (Ctrl+E) 40 for all (paler
# in the picture); one more Ctrl+Z.
run STUDIO.EXE -demo

key f8

key z

key x

key ctrl+1
said STUDIO step len=120
key c

key shift+v

chord z c b
