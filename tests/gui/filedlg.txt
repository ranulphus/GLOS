# Open and Save (toolkit 2, step C6; docs/v1/toolkit-2.md, Dialogs): GUITEST's two buttons, the dialogs by keys
# alone. Open from C:\GUI with the Text filter: a folder's name typed goes into it (IMG: its one text file); the
# Pictures filter; type-ahead in the list to B.JPG, which the preview pane describes; Enter opens it. Save as from
# C:\GUI\NOTES.TXT: a name without a type gets the filter's (.TXT); NOTES again asks to replace it, No, then the
# other format and Yes. (The list's Modified column is blanked in the shots: the dates are the copy's.)
