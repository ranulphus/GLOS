# Native GLOS's DOS: the checklist from RBIL

Generated by `tools/census/rbil.py` (`make rbil`) from Ralf Brown's Interrupt List, release 61 (Ralf Brown and its contributors; www.cs.cmu.edu/~ralf/files.html), with the census's results ([native-dos-census.md](native-dos-census.md)). See [native-dos.md](native-dos.md), N0 and N2.

**Scope (the owner, 2026-11-20):** every DOS function in RBIL; those of features GLOS doesn't have answered as MS-DOS 7.1 answers them when the feature isn't loaded. The census sets the order: functions programs asked for come first in each area.

**Proposed status** (for the owner's review; `OVERRIDES` in the script holds the hand-made ones): **implement**; **absent** (answered as without the feature); **null** (DOS's own null or reserved function); **callout** (DOS or Windows calls it and programs answer: GLOS's DOS makes DOS's, not Windows'); **internal** (INT 2Fh 12xxh, for TSRs and redirectors: after the core); **later** (MSCDEX, with the CD-ROM); **other** (another system's).

**Counts:** absent 90, callout 17, implement 220, internal 47, later 20, null 9, other 60 (463 entries; a function with entries for several systems is counted once).

U: undocumented (RBIL's mark). Census: how many jobs' programs asked for it.
