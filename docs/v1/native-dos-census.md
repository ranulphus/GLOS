# The INT 21h census (N0)

Generated by `tools/census/report.py` from the survey's census runs (`tools/survey/survey.py run --variant census`; Half-Life's with DOSLFN under CENSUS, `census-lfn`). Each job ran on plain FreeDOS 1.4 in Loop A with CENSUS.EXE (`tools/census/census.c`) resident first. See [native-dos.md](native-dos.md).

Columns: the function; how many jobs' programs asked for it (any caller where no program did); the programs that did (on plain DOS or under GLOS); the shell, drivers and harness tools that did too (Also); from where (P the program's own memory, O elsewhere: a DPMI host reflecting a protected-mode call, a TSR, DOS's own code); calls counted (only for programs that ended inside their run: Loop A stops the PC when a program says HX-DONE, before it ends; `-` when none did).
